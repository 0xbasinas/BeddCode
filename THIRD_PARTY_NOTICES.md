## Open Cascade Technology (replicad-opencascadejs)

The CAD worker loads `replicad-opencascadejs` from npm. That package is LGPL-2.1. BeddCode ships
the WASM binary unmodified and does not copy OpenCascade C++ or the opencascade.js glue into this
repository.

Source for the WASM build, including the build scripts that produce it:
<https://github.com/sgenoud/replicad/tree/main/packages/replicad-opencascadejs>

Open Cascade Technology itself:
<https://github.com/Open-Cascade-SAS/OCCT>

The LGPL-2.1 license text is the `LICENSE` file published in the `replicad-opencascadejs` package.
Anyone who receives the WASM binary can replace it with a modified build of that package; the
kernel talks to it only through `setOC`.
